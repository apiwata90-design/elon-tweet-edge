# Elon Tweet Edge

แดชบอร์ดช่วยตัดสินใจตลาด "Elon Musk # tweets" บน Polymarket — เปิดหน้าเว็บแล้วเห็นสถานการณ์ทันที

## มีอะไรบ้าง
- **ตลาดตอนนี้**: ยอดโพสต์สด, เวลาที่เหลือ, ความน่าจะเป็นของแต่ละ bucket จากโมเดล เทียบกับราคา Polymarket → edge และ EV (Expected Value – ค่าคาดหวัง)
- **ค่าเฉลี่ยเทียบกันได้**: 7 วัน / 1 / 3 / 6 เดือน / 1 ปี / ช่วงเดียวกันปีก่อน / 2 ปีก่อน ในหน่วย ต่อวัน, ต่อ 48h, ต่อ 7 วัน
- **ช่วงเวลา**: ชั่วโมงของวัน (เวลาไทย), วันในสัปดาห์, heatmap, รายเดือนย้อนถึง พ.ค. 2024
- **วันผิดปกติ** พร้อมเหตุผลและลิงก์ข่าว
- **อีเวนต์**: ผลเฉลี่ยในอดีต + ปฏิทินข้างหน้า + ข่าว (อัปเดตทุกชั่วโมง)

## ข้อมูลอัปเดตยังไง
| ส่วน | ที่มา | ความถี่ |
|---|---|---|
| ยอดโพสต์ / โพสต์ล่าสุด | xtracker API (ดึงจากเบราว์เซอร์คนเปิดโดยตรง) | ทุก 5/15/60 นาที (เลือกได้) |
| ราคาตลาด | Polymarket gamma-api (จากเบราว์เซอร์) | รอบเดียวกัน |
| ข้อมูลรายชั่วโมงสะสม, ข่าว, ตาราง Starship | GitHub Action → `data/*.json` | ทุกชั่วโมง |

เบราว์เซอร์จำข้อมูลไว้ใน localStorage จึงดึงเฉพาะโพสต์ใหม่ ไม่ต้องโหลด 1 ปีทุกครั้ง

## ติดตั้งบน GitHub Pages (ประมาณ 5 นาที)
1. สร้าง repository ใหม่บน GitHub (Public เพื่อใช้ Pages ฟรี)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`, `data`, `scripts`) — ลากวางในหน้า "Add file → Upload files" ได้เลย
   - ถ้าโฟลเดอร์ `.github` ไม่ติดไปตอนลากวาง: สร้างไฟล์ใหม่ชื่อ `.github/workflows/update.yml` แล้ววางเนื้อหาเอง
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. Settings → Actions → General → Workflow permissions: **Read and write permissions** → Save
5. แท็บ Actions → เลือก `hourly-data` → **Run workflow** หนึ่งครั้ง (หลังจากนั้นรันเองทุกชั่วโมง)
6. เปิด `https://<username>.github.io/<repo>/` — บนมือถือกด "Add to Home Screen" ได้

## ไฟล์
- `index.html` — หน้าเว็บทั้งหมด (มีข้อมูล snapshot ฝังไว้ ใช้ได้แม้ API ล่ม)
- `data/hourly.json` — จำนวนโพสต์รายชั่วโมงตั้งแต่ 1 พ.ย. 2025 (UTC)
- `scripts/update.py`, `.github/workflows/update.yml` — ตัวอัปเดตรายชั่วโมง
- `template.html`, `build.py` — ต้นฉบับสำหรับแก้ไขแล้ว build ใหม่ (ไม่จำเป็นต่อการใช้งาน)

## ข้อจำกัด
- โมเดลใช้รูปแบบในอดีต (60 วัน) + แนวโน้ม 7 วัน — ไม่รู้ข่าวที่ยังไม่เกิด ให้ปรับด้วยปุ่มอีเวนต์
- ข้อมูลก่อน พ.ย. 2025 เป็นค่าประมาณจากผลตลาดรายสัปดาห์ (กลาง bucket)
- ไม่ใช่คำแนะนำทางการเงิน
